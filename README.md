# 巨集自動化工具 (MacroTool)

自訂鍵盤與滑鼠動作序列的自動化工具，支援滑鼠座標移動、視窗尋找與固定位置、畫面顏色判斷、畫面圖片辨識判斷（以上兩者符合條件時執行子步驟），並可使用全域快捷鍵開始或停止巡迴執行。

## 功能特色

- 自訂鍵盤與滑鼠動作序列，依序由上往下循環執行
- 支援動作類型：
  - 按下 / 彈起 / 點擊按鍵（可錄製按鍵）
  - 移動滑鼠到指定座標
  - 滑鼠按下 / 放開 / 點擊（左鍵、右鍵、中鍵）
  - 等待指定秒數
  - 尋找視窗並固定位置（僅支援 Windows）
  - 判斷顏色（符合條件時執行子步驟）
  - 判斷圖片（符合條件時執行子步驟，使用樣板比對）
- 多組巨集設定，各自打勾控制是否受統一快捷鍵影響
- 統一快捷鍵：一鍵同時開始 / 停止所有已勾選的巨集
- 全域記錄快捷鍵：自動抓取滑鼠座標、顏色、圖片區塊並填入目前作用中的表單
- 設定可儲存與載入（`macros.json`、`pics/`）

## 需求套件與安裝

需要 Python 3.7 以上版本，安裝以下套件：

```
pip install keyboard pynput pywin32 pillow opencv-python numpy
```

## 執行方式

雙擊專案目錄下的 `啟動巨集工具.vbs` 即可啟動。

該腳本使用 Anaconda `base` 環境（`C:\ProgramData\Anaconda3`）下的 `pythonw.exe` 執行 `macro_tool.py`，不顯示命令提示字元視窗。若改用其他 Python 環境，請自行調整 `.vbs` 中的 Python 路徑。

若希望從命令提示字元執行，也可改用：

```
"C:\ProgramData\Anaconda3\python.exe" macro_tool.py
```

## 使用說明

1. 在左側「巨集清單」新增巨集並命名。
2. 在右側選擇動作類型並新增步驟，判斷顏色 / 圖片步驟可再編輯「子步驟」。
3. 使用記錄快捷鍵（預設 F8 / F9 / F10 / F11）抓取座標、顏色與圖片區塊。
4. 設定統一快捷鍵（例如 `f6`），按下即可開始 / 停止所有已勾選的巨集；也可用「手動開始/停止」控制目前選取的巨集。
5. 點選「儲存全部設定」可將設定存檔，下次啟動自動載入。

### 預設記錄快捷鍵

| 功能 | 預設快捷鍵 |
| ---- | ---------- |
| 抓取座標 | F8 |
| 抓取顏色 | F9 |
| 區塊起點 | F10 |
| 區塊終點 | F11 |

## 注意事項

1. 在 Windows 上，`keyboard` 套件要監聽全域快捷鍵通常需要以**系統管理員身分**執行。
2. 尋找視窗並固定位置功能僅支援 Windows，需要 `pywin32`。
3. 若螢幕顯示縮放比例不是 100%，擷取到的座標與實際畫面位置可能有落差，建議先將顯示器縮放設回 100% 再進行座標、顏色、圖片區塊的擷取與判斷。

## 打包成 EXE

使用 PyInstaller 打包（需先安裝 `pyinstaller`）：

```
pip install pyinstaller
```

執行打包指令：

```
python -m PyInstaller --noconfirm --onedir --windowed --name MacroTool macro_tool.py
```

- 打包完成後，執行檔位於 `dist/MacroTool/MacroTool.exe`。
- `--onedir` 為資料夾模式（較快啟動，適合含 OpenCV 等大型套件的應用）。
- `--windowed` 為無控制台視窗模式。
- 由於程式使用全域快捷鍵，建議以系統管理員身分執行 `MacroTool.exe`。
- 若使用圖片辨識功能，請確認 `pics` 資料夾中的圖片路徑有效。
